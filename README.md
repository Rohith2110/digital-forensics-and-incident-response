# digital-forensics-and-incident-response

## Overview

This repository documents practical digital forensic investigations completed during MSc Cybersecurity coursework. The project focuses on forensic evidence collection, email analysis, file carving, and incident investigation techniques using industry-standard forensic tools.

## Topics Covered

### Email Forensics
* PST file examination
* Enron email investigation
* Metadata analysis
* Keyword searching
* Evidence identification
* Email recovery techniques

### File and Memory Forensics
* File carving
* File signature analysis
* Deleted file recovery
* Hexadecimal analysis
* FAT32 investigation

## Tools Used
* Autopsy
* Aid4Mail
* FTK Imager
* Microsoft Excel

## Skills Demonstrated
* Digital Forensics
* Incident Investigation
* Evidence Collection
* Email Analysis
* File Recovery
* File Carving
* Hex Analysis
* Forensic Reporting

## Key Learning Outcomes
* Understanding forensic workflows
* Recovering deleted digital evidence
* Performing email investigations
* Identifying file signatures and metadata
* Producing forensic findings and reports

## Important Note
This repository is intended for educational and portfolio purposes only. University-provided datasets and assessment materials are not included.
